STEP-1
--------
npm create vite@latest . -- --template react

What this command does
---------------------
npm create vite@latest → Downloads and runs the latest Vite project creator.
. → Creates the project in the current folder.
--template react → Uses the React template.

If it asks:
Need to install the following packages:
create-vite@latest
Ok to proceed? (y)

Type:
y and press Enter.

STEP-4
-----------

mkdir src\pages, src\components, src\styles

is intended to create three new folders inside the src directory.

Here's what each part means:

mkdir → Make Directory (creates a folder).
src\pages → Creates a folder named pages inside src.
src\components → Creates a folder named components inside src.
src\styles → Creates a folder named styles inside src.

After creating them, your project structure becomes:

src/
├── assets/
├── components/
├── pages/
├── styles/
├── App.jsx
├── main.jsx

Why do we create these folders?
----------------------------------
pages/ → Stores complete pages/screens of your app.
Example: Home.jsx, Movies.jsx, Booking.jsx
components/ → Stores reusable UI pieces.
Example: Navbar.jsx, Hero.jsx, MovieCard.jsx, Footer.jsx
styles/ → Stores CSS files.
Example: navbar.css, hero.css, home.css
